Modal, offcanvas, collapse: notice the pattern

Three different components. The same two attributes every time:

data-bs-toggle="modal"      data-bs-target="#orderModal"
data-bs-toggle="collapse"   data-bs-target="#allergens"
data-bs-toggle="offcanvas"  data-bs-target="#sideMenu"

Learn the pattern once and you can use any of them. Look up the class names in the docs, copy the HTML, change the words.

This is a very common way to do a phone menu: a navbar that uses an offcanvas instead of a collapse, so the menu slides over the page instead of pushing it down. Bootstrap's docs call it "Navbar with offcanvas".
