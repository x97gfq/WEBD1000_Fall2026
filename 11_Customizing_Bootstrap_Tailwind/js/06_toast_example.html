A toast

The little message that slides in to say "saved". There is no data-bs-toggle="toast": a toast only appears when our JavaScript tells it to.

The three lines, word by word

  1. const toast = new bootstrap.Toast(...)
    Get the toast ready and keep it in a box called toast, so we can use it on the next line. const means "a name for something that will not change".
  2. document.getElementById("orderButton")
    Find the one element with id="orderButton" — our big blue button.
  3. .addEventListener("click", function () { ... })
    "When that gets clicked, run this." The code in the braces does not run now; it waits for the click. Everything you do in JavaScript is some version of this.

The whole thing is four English words

When the button is clicked, show the toast.

Try this: comment out the toast.show() line and click the button. Nothing happens, and the console stays empty. A toast you built but never showed is the most common "why is my toast broken" question there is.

A toast hides itself after five seconds. Add data-bs-autohide="false" to the toast to make it stay until you close it, or data-bs-delay="10000" for ten seconds.
