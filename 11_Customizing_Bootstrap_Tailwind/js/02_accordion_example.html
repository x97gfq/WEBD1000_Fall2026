Notice the ids

Every data-bs-target matches an id: #q1 to id="q1". Every data-bs-parent matches the accordion's own id="faq". Bootstrap finds things the same way CSS does — with a selector.

The collapsed class on a closed accordion button is what turns the little arrow around. The aria-expanded attribute tells a screen reader whether the answer is open; Bootstrap keeps it up to date as you click.
