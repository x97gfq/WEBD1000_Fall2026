Tooltips

The first component today that needs JavaScript we write. One line of it.

Hover over a button, or tab to it with the keyboard. Nothing happens until the script at the bottom of this page runs.

Why this one is different

A page can have hundreds of things with a title. Setting up a tooltip for every one of them, on every page, would be slow, so Bootstrap does not do it automatically. You tell it which ones you want.

The line, word by word

document
the page
.querySelectorAll('[data-bs-toggle="tooltip"]')
find every element that has that attribute — a CSS selector, same as in your stylesheet
.forEach(...)
do the next bit once for each one you found
new bootstrap.Tooltip(el)
make a tooltip out of that element. bootstrap is the name the bundle script puts on the page

Popovers work exactly the same way: data-bs-toggle="popover", and new bootstrap.Popover(el). A popover is a tooltip with a heading that stays open when you click.
